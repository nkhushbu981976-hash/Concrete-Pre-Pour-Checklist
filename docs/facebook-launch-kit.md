# ConcreteCheck Facebook Launch Kit

Website: https://concrete-pre-pour-checklist.vercel.app/

## Facebook Page setup

1. Create a Facebook Page named **ConcreteCheck** and choose the closest available construction, engineering, or software category.
2. Add the website URL above and use this short description: “A practical checklist for recording concrete pre-pour inspections, results, photo evidence, and corrective actions.”
3. Set `public/facebook-profile.png` as the square profile image (512 × 512 px).
4. Set `public/facebook-cover.jpg` as the Page cover image (1640 × 624 px). Review Facebook’s crop preview before saving.
5. Use `public/social-preview.jpg` (1200 × 630 px) as the link-sharing preview when Facebook offers an image override. The website’s Open Graph metadata also references the social preview for shared links.
